# CampXus Project Overview

## Purpose
CampXus is a modern, Firebase-powered social scheduling platform designed specifically for university students. It helps students manage their class schedules, discover and connect with classmates, and coordinate study sessions seamlessly.

## Key Features
- **Social Connections**: Find classmates by name, major, or student ID within your university
- **Friends System**: Send, receive, accept, or decline friend requests with instant notifications
- **Schedule Management**: Dual storage strategy (Firestore + localStorage) with real-time sync
- **Interactive Scheduling**: Dynamic time slots with pin mode and conflict detection
- **Privacy Controls**: Configure schedule visibility and social searchability
- **Real-time Updates**: Live notifications for friend activities and system updates
- **Modern UI**: Glassmorphism design with responsive layout

## Tech Stack
- **Frontend**: Vanilla JavaScript (ES6+ modules), Custom SPA router, Modular CSS architecture
- **Backend**: Firebase Authentication, Firestore database, Real-time listeners
- **Build System**: Vite for development and production builds
- **Testing**: Jest with ESM support and jsdom environment
- **Additional Libraries**: Tesseract.js (OCR), Playwright (browser automation)

## Project Type
Single Page Application (SPA) with real-time Firebase integration, designed as a social platform for university students with schedule coordination features.

## Target Users
University students who need to coordinate schedules with classmates and discover social connections within their academic institution.
